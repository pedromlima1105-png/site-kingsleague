# PatchKingsleague — Site Oficial

Site estático da **PatchKingsleague**, plataforma de patches e mods atualizados para jogos de futebol (eFootball, FC 25) com foco em Kings League, Queens League e ligas emergentes.

## 🚀 Deploy

Hospedado no **Vercel** via GitHub. Cada push na branch `main` faz deploy automático.

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (vanilla) com variáveis, animações e glassmorphism
- JavaScript puro (sem frameworks)
- Google Fonts (Orbitron + Sora)
- Font Awesome 6 (ícones)

## 📁 Estrutura

```
site-kingsleague/
├── index.html        # Site completo (HTML + CSS + JS em arquivo único)
├── vercel.json       # Configuração de deploy e rotas no Vercel
├── .gitignore        # Arquivos ignorados pelo Git
└── README.md         # Este arquivo
```

## ✅ Funcionalidades

- Carrinho funcional com JavaScript puro
- Checkout via WhatsApp com mensagem automática formatada
- FAQ accordion interativo
- Scroll reveal com IntersectionObserver
- Navbar com blur ao rolar
- Menu mobile (hamburger)
- Modal "Como Funciona"
- Design responsivo mobile-first
- Efeitos: glitch, scanlines, grid animado, glow neon

## ⚙️ Como rodar localmente

Abra o arquivo `index.html` diretamente no navegador — não precisa de servidor nem dependências.

## 📞 Contato / WhatsApp

Atualize o número em `index.html` buscando por `5511999999999` e substituindo pelo número real (aparece 3 vezes).
